Cloud Save Manager

A personal desktop tool that backs up PC game saves to your own Google Drive and keeps them in sync across your devices.

What it does

Some PC games have no launcher and no cloud saves. Cloud Save Manager is designed to find a game's save files, store versions of them in a folder in your Google Drive, and download the latest version on your other devices.

  • Built for Windows and SteamOS.
  • Keeps the current save and two older versions.
  • Asks before resolving a conflict between devices.

How it uses Google data

The app signs in with Google and uses the limited drive.file permission, so it can only reach files that it created or that you opened with it. It uses that access only to store and retrieve your game saves. Read the Privacy Policy for details.

Who it's for

This is an independent personal project by Uzair Sohail. It isn't a commercial service, and it isn't affiliated with Google, Valve or any game publisher.
